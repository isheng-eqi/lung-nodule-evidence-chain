## 核心结果（全部可复算）

| 维度 | 结果 |
|---|---|
| 三行业规范 → 条款 | 医疗 **18** / 金融 **61** / 制造 **102** 条 |
| 对象三元组 | 64 / 96 / **190** |
| 术语覆盖率 | **67.0% → 82.7%**（143/173） |
| 端到端命中率 | **100%**（宽松）/ **80%**（严格判据） |
| 真实脱敏数据集 | MedRepBench 字段级召回 **81.3%**（223 项） |
| 统一资产标识 | **7/7 一致** |

### 消融实验：双驱动到底带来什么

| 指标 | A 双驱动 | C 仅图谱 | B 仅检索 |
|---|---|---|---|
| 条款命中率 | **100%** | **100%** | 67% |
| **禁忌提示覆盖** | **2/3** | **0/3** | 0/3 |
| **信息不足仍给建议** | **0** | 0 | **2** |

**A 与 C 命中率完全相同** —— 所以我们**不声称**"双驱动提高了准确率"。
但**只有双驱动能带回"不该做什么"**：禁忌来自原文 CAVEAT 段落，图谱三元组里没有。
