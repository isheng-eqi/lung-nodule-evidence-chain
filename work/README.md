# 工作区（work/）

> **这里是队友的工作目录。交付物在 `提交包/`，那份不要动。**
>
> 为什么分开：`提交包/` 里有一份 `CHECKSUMS.sha256`（132 条文件指纹）。
> 在里面跑 Python 会生成 `__pycache__`，**校验立刻失效**；改任何文件同理。

## 目录

| 目录 | 任务 | 产出物 |
|---|---|---|
| `01_端到端重复评测/` | 跑 3 次端到端评测，报波动 | `run1~3.json` + `汇总.md` |
| `02_复现指南实测/` | 按原文逐条跑 8 组命令，记录报错 | `实测表.md` + `报错原文.txt` |
| `03_语料调研/` | 找"以表格为主"的公开规范 | `<语料>.txt` + `来源说明.md` |
| `04_开源就绪检查/` | 凭据扫描 + 开源材料核对 | `扫描结果.md` |

## 三条纪律

1. **报错原样贴**，不要改路径绕开 —— 报错本身就是结果
2. **数字不对不要改** —— 重跑一次，两次都记下来
3. **不 commit `__pycache__`** —— 仓库根 `.gitignore` 已挡住，别用 `-f` 强加
