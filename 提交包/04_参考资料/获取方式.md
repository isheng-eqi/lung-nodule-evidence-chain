## 获取原文后怎么用

```bash
cd 02_代码与本体/kg-service

# 1) 把自己下载的原文放到本目录（04_参考资料/），并用上表的文件名命名
# 2) 跑清洗
python3 clean_corpus.py --input <原文> --out <清洗后>

# 3) 跑三领域迁移验证 → 期望 18 / 61 / 102 条
python3 workflow_template.py --validate --corpus-dir ../../04_参考资料/ --out /tmp/m.json
```

> **⚠️ 注意**：医疗侧条款数取决于所用语料版本。
> `03_验证与数据/多行业迁移验证报告.json` 里记录的是
> **2024 共识全文** 的 **18 条**。

## 为什么不直接放全文

| 原因 | 说明 |
|---|---|
| **版权** | 期刊 / 学会文档的版权归原发布机构，开源再分发需另行授权 |
| **许可** | 这些文档标注的是"**可引用，需标注完整出处**"，不等于"可自由再分发" |
| **可复现性不受影响** | 清洗脚本 + 出处链接 = 任何人都能重现同样的语料 |
| **合规** | 竞赛要求"入围总决赛后开源"，本仓库即为该开源版本 |
