## 主要依据

**《肺结节诊治中国专家共识（2024年版）》**

- 发布机构：中华医学会呼吸病学分会、中国肺癌防治联盟专家组

# 三、标准体系（本体对齐目标）

| 标准 | 全称 | 对齐内容 |
|---|---|---|
| **ACR Lung-RADS** | Lung CT Screening Reporting & Data System | 肺结节影像报告与数据系统 |
| **SNOMED CT** | Systematized Nomenclature of Medicine — Clinical Terms | 临床医学术语标准 |
| **ICD-10** | International Classification of Diseases, 10th Revision | 国际疾病分类 |
| **LOINC** | Logical Observation Identifiers Names and Codes | 检验检查项目编码 |

**本体中共 18 处 `skos:closeMatch` 对齐**，使知识资产可跨机构互操作。

# 六、本项目产出物（可复用的知识资产）

| 产出物 | 说明 |
|---|---|
| `lung_nodule_ontology.ttl` | OWL 本体（Turtle 格式），57 类 / 18 条款锚点 / 18 处标准对齐 |
| `clauses_table.csv` | 18 条款 × 14 字段的结构化表格 |
| `kg_mcp_server.py` | 7 个工具的 MCP Server |
| `workflow_template.py` | 领域无关的工作流模板（含医疗、金融两个内置领域） |
| `eval_runner.py` + `evalset.json` | 自测评测集与执行器 |

**以上产出物均设计为可复用**：本体可被任何 OWL 工具加载；
工作流模板换领域只需替换种子本体与语料。

# 七、引用规范说明

本项目在构建本体与知识图谱时，**所有类、属性、约束均可溯源至具体条款**
（以 `【推荐意见N】` 标注），且**不产生新的医学主张**。

本体的 `rdfs:comment` 字段中保留了原文要点与出处，
便于人工审核与后续版本维护。
