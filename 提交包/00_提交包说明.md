## 4.2 关键步骤

### A. 知识构建流水线（从原始文档到 OWL 本体）

```bash
# 1. 语料清洗（去除引文元数据 / 页眉页脚 / 参考文献）
python3 kg-service/clean_corpus.py \
    --input 原始指南.txt --out clean.txt --report

# 2. 本体半自动化构建（条款切分 + 受约束抽取 + 强制对齐）
python3 kg-service/ontology_builder.py \
    --input clean.txt \
    --out-ontology seed_ontology.json \
    --out-triples triples.jsonl \
    --report

# 3. 导出标准 OWL 本体
```
