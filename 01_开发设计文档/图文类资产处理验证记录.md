# 一、为什么需要这条流水线

本项目此前已验证**文本类**与**表格类**资产的处理路径：

| 模态 | 处理路径 |
|---|---|
| 文本 | 文档 → 条款切分 → 本体对齐 → 图谱 |
| 表格 | 条款结构化 → CSV → 资产标识 |
| **图文** | **图片 → VLM 识别 → 事实抽取 → 图谱推理 ← 本条流水线** |

**图文类资产的特殊性**：信息以**图像形态**存在，无法直接做文本切分，
必须经过视觉语言模型（VLM）转成结构化事实后，才能进入知识图谱推理链路。

# 二、流水线设计（四步）

```

│          ← 真实场景中为 CT 报告扫描件或系统截图                    │

                            ▼
┌────────────────────────────────────────────────────────────────┐
│  第 2 步  VLM 识别（Qwen3-VL-8B-Instruct）                       │
│          用结构化 prompt 约束输出格式，从图片抽取患者事实           │
│          输出：JSON（最大径/密度类型/实性成分/年龄/性别/            │
│                     吸烟年数/影像特征/检查项目）                    │
└───────────────────────────┬────────────────────────────────────┘
                            ▼
┌────────────────────────────────────────────────────────────────┐
│  第 3 步  知识图谱推理                                            │
│          把结构化事实转成自然语言描述 → 送入推理引擎                │
│          输出：条款定位 + 多跳推理链 + 禁忌判定 + 分级诊疗          │
└───────────────────────────┬────────────────────────────────────┘
                            ▼
┌────────────────────────────────────────────────────────────────┐
│  第 4 步  资产标识                                                │
│          生成六维标识，含与图谱的挂载点（concepts / clauses）      │
└────────────────────────────────────────────────────────────────┘
```

# 五、技术要点

## 5.1 为什么用结构化 Prompt 约束 VLM 输出

如果让 VLM 自由输出，会得到一段自然语言描述，无法直接送入推理引擎。

**本方案的做法**：

1. 在 prompt 中**明确给出 JSON schema**
2. **枚举可选值**（如密度类型只能是三个规范术语之一）
3. 明确要求"缺失字段填 null，不要编造"
4. 明确要求"只输出 JSON，不要任何解释文字"

**效果**：8 个字段全部正确，且可直接 JSON 解析，无需二次清洗。

## 5.2 事实到推理引擎的转换

推理引擎的输入是自然语言描述，因此需要把结构化 JSON 转回文本：

```python
def facts_to_description(facts):
    parts = []
    if facts["年龄"]: parts.append(f"{facts['年龄']}岁")
    if facts["性别"]: parts.append(facts["性别"] + "性")
    if facts["最大径_mm"] is not None: parts.append(f"{facts['最大径_mm']}mm")
    if facts["密度类型"]: parts.append(facts["密度类型"])
    ...
    return "，".join(parts) + "，该如何处理？"
```

**这个设计的好处**：推理引擎无需为多模态单独实现接口，
**任何来源（文本提问 / 表格数据 / 图片识别）只要转成同一种描述格式即可复用同一条推理链路**。
