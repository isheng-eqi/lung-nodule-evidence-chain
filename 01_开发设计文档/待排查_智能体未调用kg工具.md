# 一、根因（证据确凿）

**智能体的活动版本上没有挂载 `kg_*` 工具。**

```
agent feijiehe  current_version_no = 3（状态 RELEASED）

各版本挂载的工具数：
  version 0 : 8 个（1 内置 + 7 个 kg_*）
  version 1 : 1 个
  version 2 : 1 个
  version 3 : 1 个   ← 只有 knowledge_base_search，**当前生效的就是这个**
```

**平台解析逻辑**：`northbound_service.py:687`
```python
version_no = agent.get("current_version_no")
```

**而约束提示词第 5 条写着**：
> 「优先调用 `kg_consult_decision` 获取带条款编号的处置依据链与推理路径」

**即：提示词要求调用一个在该版本上根本不存在的工具。**

## 1.1 成因

第五十一轮之前，我手工把 8 个工具实例插入到 `ag_tool_instance_t` 时，
**固定用了 `version_no=0`** —— 而 agent 的实际活动版本是 3。

**这是"直接改数据库"绕过平台版本管理机制的后果。**
平台的正确做法是通过版本发布流程把工具随版本一起发布。

---

# 二、修复

把 version 0 的 8 个工具实例复制到 version 3（agent 的活动版本）：

```sql
INSERT INTO nexent.ag_tool_instance_t
  (tool_id, agent_id, params, user_id, tenant_id, enabled,
   created_by, updated_by, delete_flag, version_no)
SELECT tool_id, agent_id, params, user_id, tenant_id, enabled,
       created_by, updated_by, 'N', 3
FROM nexent.ag_tool_instance_t
WHERE agent_id=2 AND version_no=0 AND delete_flag='N'
  AND tool_id NOT IN (
      SELECT tool_id FROM nexent.ag_tool_instance_t
      WHERE agent_id=2 AND version_no=3 AND delete_flag='N');
```

**结果**：version 3 现挂载 **8 个工具**（1 内置 + 7 个 `kg_*`）。

# 三、★ 排查过程中我犯的两个错（都导致假阴性）

## 错误 1：取错了 SSE 事件

| 事件类型 | 条数 | 内容 | 是不是答案 |
|---|---|---|---|
| **`final_answer`** | 1 | 948 字符 | ✅ **是** |
| `agent_new_run` | 2 | 1,454 字符 | ❌ **运行环境说明**（Run workspace / code executor 规则） |
| `model_output_deep_thinking` | 1,136 | 流式思考分片 | ❌ |
| `search_content` | 1 | 知识库命中片段 | ❌ |

**我前两版分别取「最后一条 `agent_new_run`」和「拼接全部 `agent_new_run`」，
拿到的都是运行环境说明** —— 因此判定全为"无引用"。

**教训**：SSE 事件流里 `agent_new_run` 不代表"新的一轮回答"，
它承载的是运行环境上下文。**必须先 dump 事件类型清单再写解析。**

## 错误 2：拒答判据太严

原判据只查"请补充 / 无法 / 缺少 / 信息不足"等词，
但智能体的实际输出是**结构化追问表单**：

```
1. 结节最大径是多少毫米（mm）？
2. 结节的密度类型是哪一种？
   - 实性结节 / 纯磨玻璃结节（pGGN）/ 部分实性／混杂磨玻璃结节（mGGN）/ 报告未写明
3. 是否存在以下肺癌危险因素？
   - 吸烟史／长期二手烟暴露 / 职业暴露 / 慢性肺部疾病 / 肿瘤史 / 家族史 / 无以上因素
```

**不含这些关键词，因此 3 条拒答例全被判错** —— **是判据的问题，不是系统的问题。**

**修正**：按"追问的表征"判定（含问号 / 含关键词 / 出现 ≥2 个待补字段名）。

> **这两条若不修，我会写出"智能体完全失效"的错误结论。**
> 记录下来，作为"评测工具本身也需要被审计"的实例。
