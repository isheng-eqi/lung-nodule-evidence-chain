## 六、架构分层说明

```
应用层   肺结节处置助手（面向基层医生的决策支持）
              │
编排层   Skill: lung-nodule-decision（事实层 / 推理层 / 证据层）
              │
工具层   ┌─ Nexent 内置工具（检索）
         └─ 自研 MCP 工具（推理）  ← 本项目贡献的核心增量
              │
服务层   ┌─ Elasticsearch 知识库（Nexent 提供）
         └─ 知识图谱服务（自研，MCP 协议暴露）
              │
知识层   ├─ 领域本体（OWL/TTL，57 类 / 18 条款锚点）
         ├─ 知识图谱（110 对象三元组 + 36 数据属性）
         └─ 数据资产标识（六维标识，7 资产 / 3 模态）
              │
数据层   3 份公开指南 + 1 份结构化表格 + 1 份影像报告样例
```

**关键设计**：工具层明确分为"平台提供"与"自研"两类，
这不是重复建设，而是在**平台的空白处扩展** ——
Nexent 提供检索能力，本项目补上推理与溯源能力，二者构成检索-推理双驱动。
